  Execute tests
  Returns: execution_id

GET /api/tests/status/{execution_id}
  Get execution status
  Returns: current progress, metrics

GET /api/tests/results/{result_id}

  Returns: CollectedResults

  Returns: HTML page

  Get test history
  Returns: list of results

POST /api/tests/compare
  Compare two results
  Returns: Comparison object

GET /api/tests/flaky
  Get flaky tests
  Returns: FlakyTest list

GET /api/tests/regressions
  Get regressions
  Returns: Regression list

GET /api/dashboard
  Serve main dashboard
  Returns: HTML page
